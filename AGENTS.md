# Project instructions

- Non-trivial engineering work (bug fix, feature, perf, investigation, plan, review, migration, verification): use the `poteto-mode` skill. It picks the playbook and runs supporting skills as steps need them.
- Casual turns or explicit opt-out: do not force `poteto-mode`.
- TS/React stack: follow `typescript-best-practices`. Repro/verify on the real surface before claiming done.
